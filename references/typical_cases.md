# 重点典型案例（05）遴选与归档规则

## 归档原则（用户 2026-10-27 定稿）

- **重点典型案例要「再次归入」来源大类**：同一份决定书**两处都要留存**——
  既在 `05_重点典型案例/<子类>/` 留一份，也**必须**按其来源留在
  `01_中基协…/` `02_各地证监局…/` `03_交易所…/` 下的违规实质子分类里。
- **非典型案例**只按违规实质归入来源大类的子分类，不进 05。
- 台账「是否典型案例」列：典型案例填 `是`，其余填 `否`。

> 这是本库此前最大的实现缺口：`init_library.py` 只创建了 05 的空子目录，
> 而没有任何脚本往里放文件、也没有交叉归档。v3（30 天）构建因此 05 全空。

## 遴选方式

典型案例是**人工遴选**的。`scripts/finalize_library.py --typical` 按本表匹配并归档。

- **匹配范围**：台账 D 列「被处罚机构/人」+ F 列「核心处罚事由」。
  **不拿 PDF 全文匹配**——决定书常整段引用法条（如"关联交易"出现在援引条款里），
  全文匹配会把大量普通案件误判成典型（2026-10-27 实测：误标 125/499 = 25%）。
- **限定违规类型**：填了就必须同时满足该分类，否则不入选（防止跨类误命中）。
- **主体名最稳**：玖瀛、腾创、台州沃源这类按主体名命中，不依赖语义。

| 05 子类 | 匹配关键词（D 列主体 / F 列核心事由） | 限定违规类型 | 说明 |
|---|---|---|---|
| 玖瀛资产+腾创投资案 | 玖瀛资产、玖瀛、腾创投资 | （不限） | 用户点名的重点案，两个主体成套归档 |
| 台州沃源复核案 | 台州沃源 | （不限） | 机构+法定代表人+合规风控负责人+基金经理成套复核案 |
| 关联交易典型案例 | 关联交易、利益输送、自融 | 03_投资运作、关联交易、利益输送 | 须确属投资运作类 |
| 募集宣传自媒体违规案例 | 自媒体、朋友圈、微信公众号、公开宣传 | 01_募集与适当性违规 | 须确属募集类 |
| 风控负责人履职违规案例 | 风控负责人、合规风控负责人、合规负责人 | 04_内控治理、人员资质、风控缺位 | 须确属内控治理类 |

## 使用

```bash
"<托管Python>" scripts/finalize_library.py --root "<案例库根>" --typical
```

脚本会：先把全表「是否典型案例」重置为 `否`，再按本表匹配 →
把决定书 PDF **复制**一份到 `05_重点典型案例/<子类>/`
（原件仍留在来源大类子分类中，两处并存）→ 命中行置 `是`。可重复执行（幂等）。

## 维护

新增/调整典型案例时**改本表即可**，不要改脚本硬编码。
若某类典型案例数量明显偏多（>10%），说明关键词过宽，应收紧到主体名或加限定分类。
