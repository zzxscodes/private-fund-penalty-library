# 三核心列 + 处罚措施 规则化抽取规范（v2 强制，代码实现）

> 适用：本技能**一切**需求（三核心列、处罚措施、文件命名、分类、窗口筛）都遵循同一原则——
> **先总结信源决定书的「确定文章结构」，再写固定规则 + 正则抽取，最后用代码回归测试验证**，
> **禁止让模型逐条猜测**。本文件是把该原则落到三核心列与处罚措施上的具体规范。

## 0. 通用原则（贯穿本技能）

1. 任何字段的提取，先问「这句话在决定书里有没有确定的位置/句式」。有 → 写规则；没有 → 诚实标注（如"待补""系基于…认定"），绝不编造。
2. 规则用正则 + 固定停用词实现，放在 `scripts/extract_core.py`，**不调用模型**。
3. 每次改动后跑 `scripts/selftest_extract.py` 全量回归（189 证监局 + 34 中基协），要求：
   - 三核心列 + 处罚措施 **空 0**；
   - 处罚措施**不得混入**复议/诉讼/缴款模板（如不服、人民法院、汇交国库…）。
4. 抽取前必须**去空格 / 容忍 `\s*`**：csrc.gov.cn 内联文本与部分 OCR 会在字间插空格（如 `将 罚 款`），且决定书正文常含硬换行 `\n`。

### 0.1 三层契约（用户 2026-10-26 硬性要求，禁止模型猜测）

本技能**任何需求**都遵循同一契约，三核心列 / 处罚措施 / 文件命名 / 分类 / 窗口筛概莫能外：

| 层 | 谁做 | 行为 | 结果 |
|----|------|------|------|
| **① 规则层** | `extract_core.py`（纯正则，0 模型） | 按各信源「确定文章结构」抽取 | 有确定内容 → 直接用 |
| **② 模型兜底层** | 主会话 / 子代理（仅当①返回空） | 规则对某列返回空 = 该列「无确定内容」→ 才交模型读全文定 | 模型找到 → 用模型值；模型也无 → ③ |
| **③ 诚实标注层** | 收口函数 | 模型也无 → 落诚实标记 | 按列语义：核心处罚事由/证据=`无`；核心处罚依据=`正文未载明处罚依据`；处罚措施=`不明确` |

落地函数（均在 `extract_core.py`）：
- `extract()`：纯规则层，返回 `dict(grounds,evidence,legal_basis,measures)`，空列返回 `""`。
- `mark_pending(rule)`：把空列升格为哨兵 `PENDING_MODEL = "（待模型确认）"`，触发②。
- `finalize(pending, model_filled)`：把 `PENDING_MODEL` 收口为「模型填值 或 ABSENT_MARKERS 诚实标记」。
- `extract_with_contract(text, source, model_filled=None)`：一键走完①②③，对外主入口——
  **调用方拿到的永远是「有确定内容 或 诚实标记」，绝不会出现裸空串**（裸空串=漏标，会让下游误判"已填"）。

要点：
- **顺序不可颠倒**：规则没穷尽前，绝不提前交模型；模型是兜底，不是首选。
- **禁止编造**：③ 的标记是「诚实说明缺什么」，不是「编一段凑数」。
- **下游入库用 `extract_with_contract`** 或显式 `finalize(mark_pending(...))`，保证台账不出现空的三核心列/措施。

## 1. 三类决定书固定文章结构（实测总结）

### 1.1 中基协 纪律处分 / 复核决定书

```
一、基本事实
   经查，X 存在以下违规行为：一是…… 二是…… 三是……   ← 核心处罚事由（加粗引导句 + 说明，按编号列全）
   X 上述行为违反了《……》第三十条 ……                ← 核心处罚依据（被违反的法条，含条款号）
   以上事实有 …… 等证据予以确认 ……                  ← 核心证据材料（"以上事实有…等予以确认" 之间）
二、纪律处分决定  →  协会决定：撤销/取消/公开谴责/加入黑名单……   ← 处罚措施
```

- **措施动词多样**：撤销管理人登记 / 取消会员资格 / 公开谴责 / 加入黑名单 / 暂停受理备案 / 警告 /
  认定为不适当人选 / 取消基金从业资格。**不靠动词白名单**，直接取 `协会决定` 之后、复议模板之前的段落。
- **复核决定书**结构不同：`一、纪律处分情况 / 二、申辩意见 / 三、复核意见 → 协会决定：维持原处分`。
  无独立 `二、纪律处分决定` 段，靠 `协会决定` 兜底定位；其措施多为"维持《决定书》（…）对申请人作出的纪律处分决定"。
- 证据：绝大多数以"以上事实有…等证据予以确认"句式列明；少数（如部分复核/引用行政处罚的）用
  "等证据予以确认，事实清楚…足以认定" —— 未命中句式时诚实标注，不编造。

### 1.2 证监局 行政监管措施 / 行政处罚

```
经查 / 经查明，X 存在以下违法（规）事实：一是…/一、…   ← 核心处罚事由（止于 违反了/上述事实/上述违法事实/本局认为/我会认为/经复核）
…… 违反(了) 《……》第X条 ……                        ← 核心处罚依据（被违反的法条，含条款号）
根据 / 依据 / 依照 《……》的规定，我局/本局决定：……    ← 核心处罚依据（处罚授权法条，含条款号）
我局/本局/本所决定 对你公司（及责任人）采取……措施       ← 处罚措施
```

- **证据**：仅约 9% 正文写"以上事实有…等证据"；其余无显式清单 → 诚实标注
  "（本决定书未逐项列明证据材料，系基于属地证监局监督检查及机构报送信息认定）"。
- **行政处罚（非监管措施）**：`我局决定：一、没收违法所得…；二、罚款…`，其后紧跟**缴款指令**
  （"当事人应自收到本处罚决定书之日起15日内，将罚没款/罚款直接汇交国库"）—— 必须截断，不得并入措施。
- 个别文书（如江西证监局〔2026〕20号）**无"X决定"标记**，措施由 `根据《…》的规定，对你公司及…采取…措施`
  直接引出 → 兜底直接定位 `对X采取…措施` 措施动词句。

### 1.3 交易所 监管措施决定书

- 结构与证监局完全一致（经查明…存在以下…事实 → 违反 → 本所决定），**复用 `extract_csrc`**。

## 2. 代码实现（`scripts/extract_core.py`）

- `extract(text, source)` 分发：`amac* → extract_amac`；`csrc/exchange → extract_csrc`。
- **`_legal_basis`**：抽取 `违反(了)?《X》…`（被违反条款）+ `根据/依据/依照《X》…决定`（授权条款）；
  **去重按「法规名 + 条款」**（同一部法被违反条款与授权条款都保留）；`re.S` 跨换行；
  容忍 `违反 《` / `第 十 条` 间的空格。
- **`_measures`（证监局/交易所）**：
  1. 优先定位带主语的"X决定"标记（我局决定/本局决定/现决定/本所决定/我会决定/协会决定）；
  2. **排除** "本决定(书)/处罚决定书" 文书自称；
  3. 取**第一个**通过候选（真正主处罚决定最早出现；缴款/复议模板在其后）；
  4. 截掉 `复议/诉讼/缴款` 模板（如不服/如果对本/复议与诉讼期间/汇交/将罚款/将罚没款）；
  5. 兜底：无"决定"标记时直接定位 `对X采取…措施` 措施动词句。
- **`_measures_amac`**：定位 `二/三、纪律处分决定` 或 `协会决定`，截掉复议模板与落款页脚
  （中国证券投资基金业协会/抄送），去掉 `根据《…》相关规定，协会决定` 与 `作出以下纪律处分：` 引导语。
- **`_enum`**：按 `一、/二是` 拆分有序条目，保留引导词（核心处罚事由列全）。
- **evidence 兜底**：证监局/交易所无显式证据清单 → 诚实标注；中基协未命中"以上事实有"句式 → 诚实标注。

## 3. 校验结果（189 证监局 + 34 中基协 全量回归，`selftest_extract.py`）

| 信源 | 处罚措施空 | 处罚依据空 | 证据材料空 | 复议/诉讼模板误入 |
|------|-----------|-----------|-----------|------------------|
| 证监局 (189) | 0 | 0 | 0 | 0 |
| 中基协 (34)  | 0 | 0 | 0 | 0 |

→ 三类决定书均可规则化稳定定位处罚措施，**故 v2「处罚措施（管理人+高管）」列保留**（其"是否必填"
由"能否规则化抽取"决定；现已可，故必填）。文件命名维持 `管理人全称.pdf / 职务姓名-管理人全称.pdf`。

## 4. 列设计决策（用户 2026-10-26 裁定，已验证后可执行）

- **处罚措施（管理人+高管）列 = 必填**（因三类均可规则化抽取见上）。
- **管理人名称** 列 = 机构/人员名称（v2 口径：管理人注册全称 = 聚合键）。
- **一行 = 一个案例，机构与高管合并**；处罚措施列分述「管理人：…；高管（职务姓名）：…」。
- **文件命名**：`管理人全称.pdf` / `职务姓名-管理人全称.pdf`（机构名称对应关系，遵循原官网标题 + 决定书内容）。

## 5. 坑点（回写，禁止重蹈）

- csrc.gov.cn 内联文本插空格（`将 罚 款`）→ 截断正则前必须先去空格或容忍 `\s*`。
- 硬换行 `\n` 阻断 `.*?` → 法律条款抽取用 `re.S`。
- 复核决定书无 `二、纪律处分决定` 段 → 靠 `协会决定` 兜底；河北 4 号（`行政处罚决定`）全角标点 +
  换行导致 `违反《》` 漏匹配 → `re.S` 修复。
- 复议/诉讼模板含"监督管理措施不停止执行" → 强动词白名单（`采取/责令改正/警示函/罚款/撤销/暂停/没收/公开谴责/认定为不适当人选`）排除，避免把模板误判为处罚决定。
- 同一部法的"被违反条款"与"授权条款"都要保留 → 去重按 `法规名+条款`，而非仅法规名。
- 缴款指令（`汇交国库`/`将罚没款`）必须截断，否则处罚措施混入缴款流程。
